# Aegis Legacy: System Architecture
## The Tri-Agentic Model (TAM)

This document defines the interaction between the three core agents within the Aegis Legacy Protocol.

### 1. The Vigil Agent (Input Layer)
* **Role:** Continuous surveillance of data streams.
* **Focus:** Government records, asset reclamation lists (Lost and Found Money), and real-time news feeds.
* **Action:** Flags incoming data for verification.

### 2. The Validator Agent (Verification Layer)
* **Role:** The "Truth Engine" core.
* **Focus:** Cross-referencing Vigil's data against historical records and AI-driven analysis via Google AI Studio.
* **Action:** Assigns a "Reality Score" to each data point.

### 3. The Executive Agent (Output Layer)
* **Role:** Final Decision & Broadcast.
* **Focus:** Public distribution and emergency notifications.
* **Action:** Triggers the mobile broadcast protocol if the Reality Score exceeds 98%.
