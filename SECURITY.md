# Security Policy: Aegis Legacy Protocol

## Reporting a Vulnerability
At Verdant Aegis Logic, security is our primary mission. If you discover a vulnerability in the Truth Engine or Proof of Reality protocol, please do not open a public issue. 

Instead, please contact the lead developer:
**Jason C. Watkins**

## Supported Versions
Only the latest Alpha/Beta builds of the Aegis Legacy Protocol are currently supported for security updates.

## Our Commitment
We utilize cryptographic hashing (SHA-256) and the Tri-Agentic model to ensure data integrity.
